# Contributing

Contributions that improve performance, accessibility, visual quality, browser support, integrations or documentation are welcome.

## Good contribution areas

- additional assistant states such as listening, thinking and error
- exact TTS waveform integration through Web Audio
- performance tuning for low-power/mobile devices
- reusable React, Vue or Svelte wrappers
- voice-agent integrations
- accessibility improvements
- visual themes that preserve the lightweight architecture

## Development

Run the project with any static HTTP server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

Keep the default experience dependency-free unless a change clearly requires otherwise.
